# Milestone L6 — GitHub Actions adapter

Scoping written from `main` at `f044143`, on the real code.

## 1. Findings on the existing code

- `adapter-github` only exports `PACKAGE_NAME`. The server and the CLI call `adapter-gitlab`
  directly.
- The workspace only knows one file, and the UI loads the first one.
- `JobSignals` carries neither action nor `container`.

## 2. Decisions

- **D1 — derived stages.** ADR 0013.
- **D2 — in-place patch, re-read.** Same contract as `adapter-gitlab`. Every operation is re-read
  against a model computed without the text, like `applyToolchain`: an unexpected shape becomes a
  rejection.
- **D3 — dispatch.** `adapterFor(file)` in `@keelson/server`, used by the store and the CLI.
- **D4 — workspace.** `.gitlab-ci.yml` then `.github/workflows/*.y{a,}ml`, sorted. The UI offers a
  file picker as soon as there are two. The toolchain and `keelson coverage` without a file apply
  to all of them.
- **D5 — detection.** `JobSignals.actions` and `detect.actions` on the catalogue entries whose
  official action exists. `container` and `docker://` count as an image.
- **D6 — corpus.** 22 MIT files from `actions/starter-workflows`, pinned SHA, notice reproduced.

## 3. API

## 6. Definition of done

1. Workflows read and written by the same operations, four properties at 500 runs.
2. Corpus under a verified licence, licence guard, goldens reviewed.
3. `uses:` reported by a dedicated code, coverage as a lower bound.
4. Detection in the workspace, file picker, `github` snippets inserted.
5. `validate`, `coverage`, `export` on GitHub Actions.
6. `shape`, `critique`, `audit`, `polish`, `document` if the tokens change.
7. Independent review, counter-review, full verification, merge, log.

## 7. Interface scoping (`/impeccable shape`)

**Operate** mode, no new surface apart from a file picker; assumptions settled here, the autopilot
rules out interactive validation.

- **File picker**: a `select` in the header in place of the path, only from two files upwards.
  Switching files clears the history of the file left.
- **Pipeline view**: columns are named `level N`, which the column header states as is. Stage
  controls disappear, they would have nothing to write.
- **Forms**: new job without a stage, need without options.
- **Reusable workflow**: the partial-pipeline banner says so, in its own words.
