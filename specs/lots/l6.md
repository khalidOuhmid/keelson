# Lot L6 — adaptateur GitHub Actions

Cadrage écrit depuis `main` à `f044143`, sur le code réel.

## 1. Constats sur l'existant

- `adapter-github` n'exporte que `PACKAGE_NAME`. Le serveur et la CLI appellent `adapter-gitlab` en dur.
- Le workspace ne connaît qu'un fichier, et l'UI charge le premier.
- `JobSignals` ne porte ni action ni `container`.

## 2. Décisions

- **D1 — stages dérivés.** ADR 0013.
- **D2 — patch en place, relu.** Même contrat que `adapter-gitlab`. Chaque opération est relue contre
  un modèle calculé sans le texte, comme `applyToolchain` : une forme imprévue devient un refus.
- **D3 — aiguillage.** `adapterFor(file)` dans `@keelson/server`, utilisé par le store et la CLI.
- **D4 — workspace.** `.gitlab-ci.yml` puis `.github/workflows/*.y{a,}ml`, triés. L'UI offre un choix de
  fichier dès qu'il y en a deux. La toolchain et `keelson coverage` sans fichier portent sur tous.
- **D5 — détection.** `JobSignals.actions` et `detect.actions` sur les fiches dont l'action officielle
  existe. `container` et `docker://` valent une image.
- **D6 — corpus.** 22 fichiers MIT d'`actions/starter-workflows`, SHA épinglé, notice reproduite.

## 3. API

```ts
// @keelson/adapter-github
parse(text, { file }): ParseResult; apply(document, operation): Result<ApplyOk, ApplyError>;
WORKFLOWS_DIR;
```

## 4. Écarts traités

« GitHub Actions n'est pas couvert ». Rechercher un workflow créé après le démarrage reste un écart.

## 6. Définition de terminé

1. Lecture et écriture des workflows par les mêmes opérations, quatre propriétés à 500 runs.
2. Corpus sous licence vérifiée, garde de licence, goldens relus.
3. `uses:` signalé par un code dédié, couverture en borne basse.
4. Détection dans le workspace, choix du fichier, snippets `github` insérés.
5. `validate`, `coverage`, `export` sur GitHub Actions.
6. `shape`, `critique`, `audit`, `polish`, `document` si les tokens changent.
7. Revue indépendante, contre-revue, vérification complète, fusion, journal.

## 7. Cadrage d'interface (`/impeccable shape`)

Mode **Operate**, aucune surface nouvelle hors un choix de fichier ; hypothèses tranchées ici, le
pilote interdit la validation interactive.

- **Choix de fichier** : un `select` dans l'en-tête à la place du chemin, seulement à partir de deux
  fichiers. Changer de fichier vide l'historique du fichier quitté.
- **Vue Pipeline** : les colonnes s'appellent `level N`, ce que l'en-tête de colonne dit tel quel. Les
  contrôles de stage disparaissent, ils n'auraient rien à écrire.
- **Formulaires** : nouveau job sans stage, need sans options.
- **Workflow réutilisable** : la bande de pipeline partiel le dit, avec ses mots.
